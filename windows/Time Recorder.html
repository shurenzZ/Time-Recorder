📖 Time Recorder 使用手册

欢迎使用 Time Recorder！这是一个帮你记录时间、安排清单、做每日复盘的小工具。数据保存在云端，电脑和手机登录同一账号即可同步。下面按页面介绍每个功能怎么用。

⏱ 计时（主页）

  • 开始 / 停止：点「开始计时」记一段时长，再点一次「停止」并保存为一条记录。
  • 正计时 / 倒计时：顶部可切换。倒计时需填时长，下方预设可直接选 25 min / 45 min / 1 h / 1.5 h / 2 h。
  • 精确到秒：时长一律按「分 + 秒」填写，记录也按秒显示（如 10分12秒）。
  • 目标时长（正计时下）：勾选「设定目标时长」可设目标，到点会弹提醒；勾选「到点自动停止并记录」则自动停表保存。
  • 暂停 / 继续：计时中可暂停，暂停时不保存，回来可继续。
  • 单次上限 10 小时：到点自动停止并记录。

🗂 计时任务选择

  • 任务统一在「📝 每日清单」中添加：计时页的「选择任务」下拉框自动列出今日清单里的任务，无需单独的task管理卡片。
  • 从清单右键某条目选「▶ 开始计时」，会自动跳到计时页并在下拉框中定位该任务。
  • 计时记录会带上所选任务的名称与标签，便于「📋 历史 / 📊 统计」按任务归类查看。

📝 清单

  • 顶部选日期，为该日安排任务。字段（内容 / 标签 / 详细时间 / 重要程度）全部可选填。
  • 重要程度分高 / 中 / 低，分别用 红 橙 黄 标注。
  • 排序：按「重要程度」整体排序；按「任务标签」则先分组、组内再按重要程度排。
  • 右键清单项可弹出菜单：开始计时 / 标记完成 / 删除。选「开始计时」会自动跳到计时页并定位该任务。
  • 完成状态双向同步：在清单勾选完成，计时页同名任务也会同步完成；反之在计时页完成任务，清单对应项也会同步完成。

📋 历史

  • 按 今日 / 昨日 / 本周 / 本月 / 全部 筛选记录，展示任务、标签、时长、日期。
  • 记录很多时自动分页（每页 50 条），底部可翻页。
  • 点「删除」可移除某条记录（不可恢复）。

📊 统计

  • 顶部显示今日 / 本周 / 累计总时长。
  • 热力图：近 70 天每天投入时长；趋势图：近 14 天时长变化。
  • 连续打卡：连续有记录的天数会显示「🔥 连续学习 X 天」。
  • 查看某天复盘：选日期点按钮，弹出那天的扇形图复盘。
  • 每日任务看板（下方新增）：选日期后展示该日清单的「完成率环形图」与「优先级分布条形图（高/中/低）」。

🌙 每日复盘

  • 在你当天首次登入网址时，立即弹出昨日的时间复盘弹窗：扇形图（按事件）+ 按标签 / 事件时长汇总。例：次日 6:30 或 9:30 登入都会立刻弹出，不再依赖固定 8:00。
  • 复盘弹窗还带一张 🕐 昨日 24 小时时间轴：按真实起止时间把每段记录铺在 24 小时刻度上，彩色片段即对应任务（颜色与扇形图一致），片段上标注任务名与持续时长，鼠标悬停可看完整信息；想回看任意一天，去「统计」页用「查看某天复盘」。
  • 前一天没有记录则不弹。弹窗点「知道了」或点遮罩即可关闭。
  • 想随时回看某天，去「统计」页用「查看某天复盘」即可。

☁ 云端同步 & 多设备

  • 数据存在云端（Supabase），电脑和手机用同一网址、同一账号登录即同步。
  • 手机：浏览器打开本网址 → 登录同一用户名密码 → 数据自动过来。
  • 分享给同学：直接把网址发给他，让他自己注册账号即可（数据各自隔离，互不可见）。

⚙️ 设置

  • 学习提醒：设定时间，到点弹窗提醒（可开浏览器通知）。
  • 🌗 深色模式：开关即时切换整站深色/浅色，状态自动保存，下次打开仍是该模式。
  • 导出：CSV（Excel 可打开）或完整 JSON 备份；导入：恢复 JSON 备份。
  • 清空数据：删除本账号全部任务 + 记录 + 清单（含云端）。
  • 🤖 AI 助手配置：填写 DashScope（阿里云百炼）API Key / 模型（默认 qwen3.8-max）即可，前端默认直连 DashScope；如需走自建后端代理，可填「后端代理地址」。

🤖 AI 助手

  • 先在「设置」页填写 API Key / 模型（默认直连 DashScope，密钥仅存本机；也可选填自建后端代理地址）。点击「测试连接」可一键验证 Key 是否有效。
  • 生成学习计划：输入目标（如「两周掌握微积分」），AI 拆成 3–5 个任务，确认后一键存入「任务」。
  • 解析文献：粘贴文本或上传 PDF / 文本文件，AI 输出内容摘要、关键概念、学习建议、难点分析；得到结果后可继续追问深化。
  • 翻译：输入文本并选择目标语言即可翻译；支持多轮追问，如“改成更正式的表达”“保留专业术语”。
  • 🔍 信息聚合搜索：只需输入一个简单问题，系统会基于 BROKE 框架自动补全背景、赋予专业角色、明确目标与输出标准（增强提示词可展开查看），再聚合相关信息作答；答复后可追加指令动态优化（Evolve）。
  • 导出为 HTML：翻译、解析文献、信息聚合搜索均支持将当前完整对话记录导出为 HTML 文件，便于归档、分享与离线阅读。
  • 调用时显示加载态；报错会提示「API Key 无效」「网络超时」等友好信息。

💡 小提示：复盘在你当天首次登入网址时弹出（需网页处于打开 / 登录状态），同一天重复进入不会重复弹。
